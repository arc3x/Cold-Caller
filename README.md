# Cold Caller

A World of Warcraft (Classic Era / Hardcore) addon for cold-calling players to fill dungeon groups. Pick classes and a level range, run `/who` searches, then whisper and track who you've already contacted.

## Scripts

Scripts live in `utils/`:

- **`build.bat`** — packages the addon into `build\ColdCaller.zip`, ready to upload to CurseForge.
- **`test.bat`** — copies the addon straight into your local WoW Classic Era `AddOns` folder for quick testing.
